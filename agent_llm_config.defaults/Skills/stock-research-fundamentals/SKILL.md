# Earnings and peers

Load **`stock-research`**. One named company per run unless they already named the peer set.

## Earnings preview

Before the company reports: last **4 quarters** of EPS vs estimates, this quarter's forecast, and what surprised last time.

1. Prefer active `financial-modeling-prep` or `alphavantage`. Recommend one if neither is active; wait before loading.
2. Use `edgartools` for the filing behind a surprise (revenue, margin, guidance language). Cite the form and date.
3. Table the four quarters from tool fields only. If the forecast is missing, say unknown.
4. Map the ticker to Hyperliquid, Arcus, Uniswap, and Aerodrome. Label venue mark vs the cash print. Research only when none lists it.
5. No buy or sell price. A trade idea is trade mode after they ask.

## Peer showdown

Compare the company with its **three closest peers** on growth, margins, valuation, and analyst forecasts. Say which looks cheapest for its growth, and why, from the same fields.

1. Peers come from the fundamentals tool. If it returns none, ask the operator for three tickers. Do not invent a peer set.
2. Same columns for all four names. Leave a cell blank when the tool omitted it.
3. One sentence on who looks cheapest for the growth you measured. State the metric. Do not turn that into an order.
4. Venue-map each name. Research only stays research only.
