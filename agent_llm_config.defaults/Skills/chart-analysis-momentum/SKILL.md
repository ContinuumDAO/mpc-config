# Chart analysis: momentum

Tool: **`continuum__analyze_momentum`**.

Summarize **`analysis.rsi`** (value, zone: overbought/oversold/neutral) and **`analysis.macd`** (histogram sign, crossover state).

Adding RSI/MACD **panes** on a chart is plotting — use `prepare_chart` overlays or local customization, not this analysis tool.
