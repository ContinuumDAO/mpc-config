Install Continuum node

Provision certificates, configuration, and start the MPC stack on this machine. Attach the node at mpa.continuumdao.org when install completes.

Fresh install only — if configs.yaml already exists under ~/mpc-config, use Maintenance in the node app to update.

WSL distro name (Windows)

Required on Windows. Run wsl -l -v in PowerShell. Install clones to ~/mpc-config in that distro (not inside the extension container). Enable WSL integration for this distro in Docker Desktop.

Provide at least one management key (Ethereum or PublicMgtKey).
